#  🚀Adult Income prediction using Logistic Regression

## 📖Description
Predicting whether an individual's annual income exceeds $50K using Logistic Regression and the Adult Census Income dataset.

## ✨Project Workflow
- Data Cleaning using pandas library
- Visualization using Matplotlib and Seaborn
- EDA using various plots like boxplot,histogram,violin plot,KDE plot,stripplot etc
- Encoding of categorical features using one hot encoder
- Scaling the features for better logistic regression model performance
- Evaluation based on different classification metrics like Accuracy,precision,recall and F1 score
